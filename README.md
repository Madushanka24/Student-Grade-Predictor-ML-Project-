# Student Grade Predictor 🎓

A web-based **Machine Learning application** that predicts student final marks and grades based on study hours, attendance, and assignment scores.  

It features **interactive charts**, **live predictions**, and a modern **Bootstrap web interface** — perfect for your portfolio!

---

## 🔹 Features

- **Linear Regression Model** trained on student data  
- **Predicts final marks and grade** dynamically  
- **Interactive Plotly charts**:  
  - Actual vs Predicted Marks  
  - Study Hours vs Final Marks  
- **Live updates**: chart updates instantly with new predictions  
- **Bootstrap UI**: clean, responsive design  
- **Model saving** with `joblib` for fast loading  
- **CSV logging** for tracking predictions (optional)
